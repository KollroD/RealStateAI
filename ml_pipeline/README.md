# ML Pipeline: Классификация авторов объявлений недвижимости

Пайплайн машинного обучения для сервиса **RealStateAI**. Определяет тип автора объявления о сдаче/продаже недвижимости.

## 🎯 Классы целевой переменной (`target`)

| Класс | Автор | Описание и критерии |
| :---: | :--- | :--- |
| **0** | **Собственник** | Объявления от прямых владельцев. Простой бытовой язык, комиссия строго 0%, маркеры «от собственника», «без комиссии», отсутствие признаков агентств. |
| **1** | **Риелтор / Агентство** | Профессиональные посредники. **Любая ненулевая комиссия (`commission > 0`) автоматически относит объявление к этому классу.** Также учитываются маркеры: «арт.», «номер объекта», «деятельность застрахована», «ипотека», «залог» и более 3 активных объявлений. Включает нормализацию латиницы (обход фильтров). |
| **2** | **Робот (LLM)** | Синтетические тексты, сгенерированные ChatGPT и аналогами. Обилие эмодзи (📍, ✨, 💰, 🏠), шаблонные буллеты, искусственные маркетинговые клише («идеальный выбор», «в самом сердце»). |

## 🛠 1. Модуль разметки (`labeling_app.py`)

Модуль реализует строгие правила и нормализацию омоглифов:
- **Нормализация текста**: заменяет латинские буквы (A, a, B, C, c, E, e, H, K, k, M, O, o, P, p, T, X, x, y), которые агенты вставляют в слова вроде «Hoмеp объектa», обратно в кириллицу.
- **Приоритет комиссии**: `commission > 0` $\rightarrow$ безоговорочно класс `1` (Риелтор).
- **Детекция LLM**: сканирование диапазонов Unicode-эмодзи и паттернов списков.

### Запуск разметки:
```bash
python ml_pipeline/labeling_app.py \
  --input ml_pipeline/data/for_model.csv \
  --output ml_pipeline/data/target_dataset.csv \
  --audit-log ml_pipeline/data/manual_evaluations.csv
```

## 🚀 2. Модуль обучения (`train.py`)

Архитектура модели:
1. **Эмбеддинги RuBERT**: извлечение 312-мерных векторов `cointegrated/rubert-tiny2` (поддержка Apple Silicon `mps`, NVIDIA `cuda` и `cpu`).
2. **Стилистические признаки**:
   - Длина текста, средняя длина слова, число слов.
   - Процент заглавных букв (`caps_ratio`).
   - Наличие списков, эмодзи, восклицательных знаков, цифр и абзацев.
3. **Табличные признаки**: цена (`price`), залог (`deposit`), комиссия (`commission`).
4. **CatBoostClassifier**:
   - `iterations=700`, `learning_rate=0.05`, `depth=6`.
   - Взвешивание классов `class_weights=[1.0, 1.0, 4.5]` для редкого класса LLM.
   - Подбор порога вероятности для детекции LLM на валидационной выборке.

### Запуск обучения:
```bash
python ml_pipeline/train.py \
  --data ml_pipeline/data/target_dataset.csv \
  --output-dir ml_pipeline/models \
  --iterations 700 \
  --lr 0.05
```
